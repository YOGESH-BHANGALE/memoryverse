# AI / LLM
# The LLM is Groq, called over its API — there is no local model, so PyTorch,
# transformers, and sentence-transformers are deliberately NOT installed. Their
# combined resident footprint (~300-400 MB) overran the 512 MB free-tier worker
# and OOM-killed it mid-upload. Embeddings come from chromadb's ONNX backend
# (below) instead. Do not re-add torch/sentence-transformers without moving to a
# larger instance — see app/core/vectordb/embeddings.py and text_splitter.py.
#
# Only two namespaces are imported: langchain_core (prompts, Embeddings base)
# and langchain_groq (ChatGroq). The `langchain` meta-package, langchain-community
# (which drags in aiohttp, SQLAlchemy, dataclasses-json), langchain-text-splitters
# and tiktoken were installed but never imported anywhere in app/ — dropped to cut
# image size and build time. Note this does NOT reduce resident memory: a package
# that is never imported costs disk, not RSS. Chunking is vendored in
# app/core/vectordb/text_splitter.py, which is why text-splitters can go.
langchain-core>=0.3.0,<0.4.0
langchain-groq>=0.2.0,<0.3.0
